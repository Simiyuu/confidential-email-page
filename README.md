# Classified Email Document

A CSS styling project that transforms standard web text into a physical, top-secret government document. This project demonstrates advanced CSS positioning, the box model, and visual effects to create an immersive, redacted aesthetic.

## Live Demo
[View the Live Project](https://simiyuu.github.io/confidential-email-page/)

## Technologies & Concepts Used
* **HTML5:** Semantic structure and inline elements (`span`) for targeted styling.
* **CSS3:** 
  * `filter: blur()` to redact sensitive inline text.
  * `transform: rotate()` to create off-axis, realistic rubber stamp effects.
  * `box-sizing: border-box` for precise dimensional control of the document container.
  * `display: inline-block` to constrain stamp borders tightly to their text.
